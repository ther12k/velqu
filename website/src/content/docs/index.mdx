```bash
bun add @velqu/core@beta
```

A Rust HTTP runtime that runs your TypeScript handlers on an embedded
quickjs-ng engine. The host routes by method/path and enforces bounded
queues, bodies, heap, stack, and deadlines **before any JavaScript runs** —
while types, runtime validation, Treaty clients, OpenAPI, and the contract
lock all derive from one schema declaration.

<CardGrid>
  <Card title="Rust routes before JavaScript">
    Method/path dispatch, body limits, and schema validation happen in the
    host. 404/405 never reach a handler; validation failures are typed 422s.
  </Card>
  <Card title="One schema contract">
    The same schema IR drives generated TypeScript types, kernel validation,
    Treaty clients, <code>openapi.json</code>, and the contract lock — no drift.
  </Card>
  <Card title="Bounded by construction">
    Queues, bodies, headers, heap, stack, handler deadlines, and pending
    operations all have enforced limits. Failures are redacted, typed RFC 9457
    problems.
  </Card>
</CardGrid>
