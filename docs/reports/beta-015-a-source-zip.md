# BETA-015-A — Source ZIP

## Overview

Verifies the **source ZIP** deliverable of the self-verifying public-beta release packet, produced by `scripts/release-packet`:

- `source-<short>.zip` is generated by `git archive` from exactly one bound source commit (with a commit-prefixed root directory), so the archive content is reproducible from the repository at that commit.
- The ZIP is listed in `SHA256SUMS.txt` and verified with `sha256sum -c` from inside the `release/` directory.
- `SOURCE-COMMIT.txt` records the full commit hash; `REVIEW_INDEX.json` and `EVIDENCE_INDEX.json` are regenerated after HEAD is fixed and grep-verified to carry the same commit, so every packet artifact maps to one source commit.
- The packet refuses to build from a dirty tree, guaranteeing the ZIP matches the committed state.

## Guardrail mapping

- **Checksums verify from release directory** — `sha256sum -c SHA256SUMS.txt` all OK (transcript above).
- **Artifacts map to one source commit** — SOURCE-COMMIT.txt, git bundle, archive, and grep-verified index bindings all reference the single HEAD commit; clean-tree requirement prevents drift.
- **SBOM identifies dependencies/licenses** — covered by the dedicated BETA-015 SBOM packet (dependency-scan evidence from BETA-009-B carries the cargo dependency inventory; license fields remain owner-gated).
- **No stale historical metadata is current** — indexes are regenerated after HEAD is fixed; the manifest is refreshed by this packet's gates.
