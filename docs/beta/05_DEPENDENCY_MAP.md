# Dependency Map

## Milestone DAG

```text
G0-GATE
  ├─→ M24-GATE → M25-GATE → M26-GATE → M27-GATE → M28-GATE → M3-GATE → M4A-GATE → BETA-GATE
  └─→ BETA benchmark infrastructure lane ───────────────────────────────────────────────┘
```

## Task dependency policy

- Dependencies are hard unless the task explicitly says a design-only lane may proceed.
- A task can be `IN_PROGRESS` with dependencies open only when it produces no runtime integration that trusts the unfinished dependency.
- Gate tasks depend on every task in that milestone.
- `BETA-017` owner decisions can proceed independently but must pass before `BETA-GATE`.
