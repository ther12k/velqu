# Agent Execution Rules

1. Work in a real Git repository with atomic task-ID commits.
2. Preserve negative historical evidence; never delete a losing benchmark.
3. Do not mark PASS from summary prose alone.
4. Every P0/P1 task needs source, tests, captured output, and required evidence.
5. Do not weaken fixtures or limits to obtain a pass.
6. Keep compiler/runtime/public contract responsibilities separate.
7. Build optional capabilities outside core and measure their cost.
8. Stop only for genuine owner/external/safety/kill-criterion blocks; continue independent work.
9. Keep a clean tree at every gate.
10. Update task state and review/evidence indexes with each checkpoint.
